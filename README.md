# Planit — GitHub + Vercel + Firebase

This build is designed so you do **not edit any Planit code**.

- GitHub stores the website code.
- Vercel deploys the website.
- Firebase Authentication provides your private login.
- Cloud Firestore stores the same Planit data across your MacBook, iPad, and phone.

## Important
Do not put passwords or Firebase service-account / Admin SDK secrets into GitHub or Vercel.
This build only needs the normal Firebase Web App values: API Key, Project ID, and App ID.

Read `SETUP-FIREBASE-VERCEL.md` for the exact click-by-click setup.
